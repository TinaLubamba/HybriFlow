    Output

    Everything is written to the output folder (HybriFlow_Output by default). Keep the files in the folder together, because the buttons and links in the HTML pages open the other files by their names.

    Files

    FileWhat it contains
    final_database.html and the folder final_database_filesThe interactive database: one row per sample, searchable, sortable and filterable, with buttons to export (Copy, CSV, Excel, Print). The page needs the final_database_files folder beside it. No internet connection or R is needed to open it.
    final_database.xlsxThe same database as an Excel workbook: control and NTC checks, genotype calls, discordant positions, repeat notes, reagent lot numbers and expiry dates, the Excel-versus-PDF consistency check, the overall QC status and clickable links to the source files.
    final_database_QC_passed.xlsxQC-passed samples, with the repeat handling you chose.
    run_summary.txtCounts, QC results, top genotypes, date range and a check of whether repeated discordant genotypes changed.
    followup_analysis.htmlThe follow-up report with tables and nine figures (only if the follow-up analysis was run).
    followup_database.xlsxOne row per woman, with her category, the flags P, C and A, and the genotypes that persisted, cleared or were acquired.
    followup_figures/The nine follow-up figures as PNG files.
    Duplicate_Excel_files_report.csv, Duplicate_PDF_files_report.csvFiles found more than once for the same Sample ID (one file per ID is used).
    Sample_IDs_without_year.csv, Sample_IDs_year_from_2digit.csvSample IDs whose visit year was missing or read from a two-digit year, for checking.
    HybriFlow_Output.zipThe output folder zipped (next to it), ready to share. Everything works once the recipient extracts it.
