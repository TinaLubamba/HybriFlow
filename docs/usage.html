    Usage

    You do not need to open or edit any script. Load the package and run one function.

    Quick start

    library(HybriFlow)
run_hybriflow()

    Two pop-up windows ask for what the pipeline needs.

    1. Choose the data folder

    Pick the parent folder that holds all the run sub-folders (the Excel files and the PDF reports, in any sub-folder).

    2. Choose how repeated samples are handled

    This choice affects the QC-passed database only. The main database always keeps every record.

    ChoiceWhat is kept in the QC-passed database
    "all"Every record, including all repeats
    "original"Only the original sample (repeat 0)
    "latest"Only the latest repeat of each sample
    "specific"Only the repeat number you choose (set with specific_repeat)

    What happens during a run

    The pipeline reads every Excel and PDF file, links them by Sample ID, runs the quality checks, builds the database and writes the results to a HybriFlow_Output folder in your current working folder, with a zipped copy next to it. Progress messages appear in the console, and the HTML report opens in your browser when it finishes.

    The first run takes longest

    The first run reads every file (about 13 minutes for 2744 files in our test). The cache is on by default, so later runs only read new or changed files. Use force_rebuild = TRUE to read everything again.

    Choosing options

    To skip the pop-ups, or to change a setting, pass arguments. All of them are listed on the Parameters page.

    run_hybriflow(
  data_folder     = "D:/hybriflow_runs",      # parent folder with all run sub-folders
  output_folder   = "D:/hybriflow_results",
  repeat_handling = "latest",                 # "all", "original", "latest", "specific"
  followup        = followup_settings(visits_required = 3)
)

    Follow-up analysis

    For studies in which each woman is followed over several visits, HybriFlow judges every baseline genotype separately:

    • Persisted: detected at baseline and at every follow-up visit.
    • Cleared: not detected at one or more follow-up visits, even if it is detected again later.
    • Acquired: absent at baseline but detected at any follow-up visit.

    Whether at least one genotype persisted (P), cleared (C) and was acquired (A) gives six mutually exclusive categories:

    CategoryPCA
    Persist onlyyes
    Clear onlyyes
    Persist + clearyesyes
    Persist + acquireyesyes
    Clear + acquireyesyes
    Persist + clear + acquireyesyesyes

    "Persist any", "clear any" and "acquire any" are reported as overlapping summaries. Persist + clear can only occur in women with two or more baseline genotypes.

    Changing the study design

    The number of study visits (baseline plus follow-ups) is a setting, so a cohort with a different design needs no code changes:

    run_hybriflow(followup = followup_settings(visits_required = 7))   # baseline + 6 follow-ups
run_hybriflow(followup = followup_settings(run = FALSE))           # skip the follow-up analysis

    Sample ID format

    <13-digit sample number>_<visit code / date>, for example 100-00-0001-0001_1-004-0_20240729. The visit year and date are read from the part after the first underscore, and repeats carry a suffix such as -1.

    Label sample IDs in this format

    Samples whose visit date cannot be read cannot be placed in visit order in the follow-up analysis, so those women are left out. Laboratories should label every sample ID in the standard format, including the visit date.

    What the files must look like

    • Sample files are recognised by a Target column and need the columns Sample ID, Target, Position, TH, LTH, Value, Result.
    • PDF reports are matched by the ID after report_ or report- in the file name, or by the ID SAMPLE printed inside the PDF.
    • A genotype is POSITIVE only if all its probe positions are positive. Disagreeing positions are flagged as discordant, which is a review flag and not a QC failure.
